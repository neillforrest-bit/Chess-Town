Dinner Town Preview
Three paths: Cook / Order in / Go out. Solo or one shared phone. One favourite and optional veto per diner; vetoed ideas excluded, votes resolve winner, ties require an explicit joint final choice. No friends messages, accounts, server persistence or transactions. Meal ideas are original static planning cards, not full recipes. Targets are rough and labels must be checked; no allergy-safety claim. Exclusion filtering only checks the listed base ingredients, not cross-contact or product ingredients. No pantry-aware search or checked recipe links yet. Order/go-out produce cuisine and budget/vibe brief only, not restaurant availability or live prices. Last-plan save writes browser local storage only; recovery UI not implemented yet.

375x667 browser QA checks: cooking setup/pair vote/pass/results/ingredient checkbox/save; solo go-out brief; split favourites explicit final choice; own town hub/menu/nav. No overflow or page errors. Native Safari not tested. Preview only, no production.
